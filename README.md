# رِواق — Premium Interior & Fit-Out Starter

موقع عربي كامل متعدد الصفحات بهوية افتراضية مستقلة. جميع المشاريع تصورات تصميمية مولدة وليست أعمال شركة فعلية. لم تُضف شهادات عملاء أو أرقام إنجازات أو قنوات تواصل مختلقة.

## التشغيل

الموقع العام بلا اعتماديات تشغيلية: HTML وCSS ووحدات JavaScript مع توليد صفحات مسبق بـNode.js. لا يحتاج خادم تطبيق أو قاعدة بيانات لعرض الصفحات. `linkedom` اعتماد تطوير لاختبارات DOM فقط.

```bash
npm ci
npm run build
npm test
python3 -m http.server 8080 --directory dist
```

افتح `http://localhost:8080`. فتح HTML مباشرة بـ`file://` لا يشغل الوحدات والمسارات المطلقة بشكل صحيح. استخدم خادمًا محليًا أو مضيف صفحات ثابتة. يوجد في `dist` نسخة مكتملة جاهزة للاستخدام حتى دون البناء.

## الملفات

| الملف أو المجلد | الغرض |
|---|---|
| `src/config.js` | الهوية، الألوان، التواصل، مناطق الخدمة، المشاريع، الخدمات والخامات |
| `src/views.js` | قوالب الصفحات والمكونات الدلالية |
| `src/styles.css` | التصميم، RTL، نقاط الاستجابة والحركة |
| `src/app.js` | القائمة والفلترة والخامات والمقارنة والمعرض ومسار الطلب |
| `src/quote-core.js` | تحقق المدخلات وإعداد النص وZIP ورابط واتساب |
| `scripts/build.mjs` | إخراج الصفحات وSEO وملفات الاستضافة الثابتة |
| `dist/` | الموقع الناتج، جاهز لخادم ثابت |
| `source-assets/` | الصور المولدة الأصلية |
| `tests/` | اختبارات المنطق والصفحات والتفاعلات في DOM محاكاة |
| `docs/` | بحث المراجع، التخصيص، القيود، تراخيص الخطوط وسجل الاختبارات |

## الصفحات

الرئيسية، من نحن، الخدمات، المشاريع، طلب عرض سعر، التواصل، الخصوصية، أربع صفحات تفاصيل مشاريع، وسبع صفحات خدمات، إضافة إلى صفحة 404. إجمالي 18 صفحة محتوى.

## طلب التسعيرة

مسار من أربع خطوات: المشروع، التفاصيل، التواصل، المراجعة. يتحقق من الحقول ورقم الجوال السعودي وملفات JPG/PNG/WebP/PDF. المرفقات بحد أقصى 5 ملفات و20 MB إجماليًا.

الطلب يبقى في ذاكرة الصفحة. لا يوجد تخزين في خادم أو متصفح ولا لوحة إدارة. النسخ ينقل النص للحافظة. تنزيل ZIP يحتوي النص والملفات المختارة الفعلية. تهيئة رقم واتساب تتيح فتح الرسالة بالبيانات دون إرسال تلقائي، والملفات تحتاج إرفاقًا يدويًا داخل واتساب.

لا تتوفر في هذه النسخة بنية قاعدة بيانات مُهيأة ومحميّة؛ استُخدم المسار البديل العملي. تحويلها إلى حفظ مركزي يحتاج backend وحماية وصول ورفع ملفات وسياسة احتفاظ، وليس تفعيل مفتاح وهمي في الواجهة.

## التحقق

اقرأ `docs/QA.md` لنتائج الاختبار وحدودها. اختبارات DOM ليست اختبارات Chrome أو Safari، ولا دليلًا على تنسيق الشاشة أو عدم التمرير الأفقي. المراجعة البصرية الفعلية للصفحات وقياسات Core Web Vitals لم تُجر في هذه البيئة.

اقرأ `docs/CUSTOMIZATION.md` قبل تخصيص النسخة لشركة فعلية، و`docs/RESEARCH.md` للبحث المرجعي.
