# نسخة معاينة باسم شركة

كل مجلد داخل `clients/` ينتج نسخة كاملة من الموقع باسم الشركة وألوانها وشعارها، وتُنشر تلقائيًا على:
`https://w7by4nrcfd-cpu.github.io/Riwag/c/<اسم-المجلد>/`

## الإضافة

1. انسخ `clients/example/` إلى `clients/<slug>/` (حروف إنجليزية صغيرة وأرقام وشرطة فقط، مثل `al-itqan`).
2. عدّل `client.json`: الاسم العربي والإنجليزي، الوصف، خمسة ألوان بصيغة `#rrggbb`، مناطق الخدمة.
3. ضع الشعار باسم `logo.svg` أو `logo.png` (يفضل خلفية شفافة ونسبة قريبة من 40×46).
4. ادفع إلى `main`؛ البناء يتحقق من صيغة الألوان ورقم واتساب ويوقف النشر عند الخطأ.

محليًا: `CLIENT=<slug> OUT_DIR=dist-client npm run build`.

## الأمانة والحقوق

- تظهر أعلى كل صفحة عبارة «معاينة مقترحة لموقع … — نموذج للعرض وليس الموقع الرسمي»، والصور تبقى موسومة بأنها تصورات مولدة. لا تُزل ذلك قبل اتفاق فعلي واستبدال الصور بأعمال الشركة.
- الروابط ممنوعة من الفهرسة، لكنها مفتوحة لمن يعرفها والمستودع عام؛ استخدم شعار الشركة وبياناتها بعد إذنها، أو اكتفِ بالاسم والألوان في العرض الأول.
- رقم واتساب المعاينة (رقم صاحب المشروع) مضبوط في `src/config.js`، وتستخدمه كل نسخة لا تحدد رقمها؛ فتصل طلبات التجربة إليك أثناء العرض. أضف رقم الشركة في `contact.whatsapp` فقط بعد موافقتها.
