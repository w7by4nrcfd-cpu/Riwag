## قيد المراجعة البصرية

تعليمات [Sites — SKILL.md](sandbox:/root/.codex/plugins/cache/openai-curated-remote/sites/1.0.1/skills/sites/SKILL.md) التي قُرئت تنص: “If `$control-browser` is unavailable, skip browser QA: do not start a preview server, install a browser, or improvise another browser-control path.” بيئة Managed Linux الحالية لا توفر `$control-browser`. لذلك لم يبدأ خادم مراجعة ولم تُختلق لقطات شاشة. المتاح هو مراجعة الصور والفحص البرمجي ومعاينة خاصة للمستخدم.

## أحجام أصول مقاسة

إجمالي مجلد الموقع الناتج نحو 4.0 MiB. JavaScript الرئيسي 16,902 بايت قبل الضغط، CSS نحو 30 KiB، وصورة المجلس 1200px: 155,690 بايت. الملفات الأصلية عالية الجودة خارج `dist`، فلا تُحمّل للزائر. الخطوط محلية مع `font-display:swap`. هذه أحجام ملفات، لا سرعة تحميل أو نتيجة CWV.

## قائمة المراجعة قبل البيع أو النشر العام

1. مراجعة 320/390/768/1024/1440/1920 بكسل دون تمرير أفقي، وفحص zoom 200% والاتجاهين.
2. تجربة القائمة وtab order والحوار وقارئ شاشة؛ فحص التباين والتركيز.
3. اختيار ملفات حقيقية، تنزيل ZIP وفكّه، تجربة حافظة iPhone وChrome.
4. إعداد رقم مصرح به، فتح واتساب والتأكد من عدم الإرسال التلقائي وإرفاق الملفات يدويًا.
5. التقاط الصفحة الرئيسية والمشاريع والطلب في Chrome وSafari، وإصلاح أي قص أو تراكب.
6. قياس Lighthouse ومؤشرات الأداء على شبكة وجهاز ممثلين، والتحقق من ترويسات الاستضافة و404 الفعلية.

النسخة قابلة للتجربة، لكنها لم تنل اعتمادًا بصريًا أو اعتماد جاهزية إنتاج نهائي.
